# Australis Project — Discord-бот

Python 3.12, discord.py, SQLite. На основе прежнего Skyfield Overwatch Unit.
Красные акценты, название Australis Project, без старого логотипа.

## Быстрый запуск

1. Создай приложение на https://discord.com/developers/applications и открой Bot.
2. В Bot включи **Server Members Intent** и **Message Content Intent**: они нужны сохранённым функциям участников и текстовых игр.
3. Скопируй `.env.example` в `.env`. Вставь токен в `DISCORD_TOKEN`, ID своего Discord-сервера — в `GUILD_ID`. Токен не отправляй в чат и не публикуй в GitHub.
4. В OAuth2 → URL Generator выбери `bot` и `applications.commands`. Добавь бота на сервер. Для основных функций нужны View Channels, Send Messages, Embed Links, Read Message History; для картинок-обновлений — Attach Files. Для дополнительных игр — Add Reactions, подписок — Manage Roles, учёта приглашений — Manage Server. Administrator не требуется.
5. Запусти одним из способов ниже. В профиле приложения задай имя **Australis Project**: код не меняет имя аккаунта автоматически.

### Обычный Python / хостинг ботов

```sh
python -m pip install -r requirements.txt
python bot.py
```

На хостинге стартовый файл — `bot.py`. Переменные можно задать через панель хостинга вместо `.env`. Папка `data` должна быть доступна для записи и сохраняться при перезапусках.

### Docker

```sh
docker compose up -d --build
docker compose logs -f
```

Docker сохраняет SQLite в именованном томе. Не используй `docker compose down -v`, если хочешь сохранить настройки и рекорды. Для резервной копии останови бота и скопируй весь каталог данных.

## Нужные тебе команды

| Команда | Что делает |
|---|---|
| `/post channel:…` | Открывает форму: заголовок, многострочный текст, необязательная HTTPS-ссылка на картинку. После отправки формы публикует панель в выбранный канал. |
| `/post_edit message_id:…` | Открывает заполненную форму существующей панели `/post`. Пустое поле картинки удаляет изображение. |
| `/collection_set url:…` | Сохраняет ссылку Steam Workshop отдельно для этого сервера. |
| `/collection` | Показывает карточку коллекции и кнопку перехода. |
| `/snake` | Личная змейка с четырьмя кнопками направлений и кнопкой завершения. |
| `/top category:Snake` | Таблица рекордов змейки. |
| `/panel` | Постоянная общая панель с профилем, статистикой и играми. |
| `/help` | Справочник команд. |

Создавать/редактировать панели и менять коллекцию могут участники с правом **Управлять сервером**. Бот повторно проверяет это право при отправке формы. Сообщения не вызывают массовых пингов. Markdown и переносы строк сохраняются. Заголовок до 200, текст до 3500 символов. Картинка в `/post` задаётся прямой доступной HTTPS-ссылкой; для загрузки файла используй `/dev_update`.

Для ID сообщения включи «Режим разработчика» в настройках Discord → Расширенные, затем ПКМ по панели → «Копировать ID сообщения». Редактируются только панели, созданные через `/post` и зарегистрированные в базе этого бота.

Ссылка на вашу коллекцию пока не задана. Выполни `/collection_set` со своей ссылкой вида `https://steamcommunity.com/sharedfiles/filedetails/?id=...`. Бот проверяет формат адреса, но не запрашивает Steam для проверки существования и типа страницы.

Змейка пошаговая: нажатие = движение на одну клетку; разворот на 180° игнорируется, движение продолжается вперёд. Стена или собственное тело завершают игру. Через 3 минуты бездействия партия заканчивается. Лучший результат записывается при завершении, включая тайм-аут. После перезапуска незавершённая партия пропадает; начни новую через `/snake`.

## Сохранённые функции предыдущего бота

- `/dev_setup`: канал подписки, отдельная роль без разрешений, канал новостей. Роль бота должна стоять выше роли подписчиков.
- `/dev_update`: заголовок, описание, вложение PNG/JPG/GIF/WebP до 8 МБ; необязательный пинг только роли подписчиков. Без `ping:true` пинга нет.
- `/pong`: пошаговая одиночная игра.
- `/profile`, `/bio`, `/stats`, `/top`, `/rep`: профиль, достижения, репутация.
- `/setup`: пять разных каналов для счёта, слов, ожидания, команд и приглашений. Настройка дополнительных текстовых игр необязательна: панели, коллекция и змейка работают сразу после запуска.
- `/invites_sync`, `/reset`: синхронизация приглашений и сброс раунда.

После `/setup` команды обычных участников ограничиваются выбранным каналом команд. Администраторам с Manage Server доступны везде. Подписка и общая панель сохраняют работоспособность кнопок после перезапуска.

Данные хранятся отдельно для каждого Discord-сервера. Для переноса старой базы останови оба бота, сделай резервную копию каталога данных и укажи `DATABASE_PATH` на копию старой SQLite; не запускай оба приложения на одном токене.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Проверены 26 автоматических тестов: правила игр, сохранение данных, подписки, публикации, доступ к новым командам, ссылки коллекций, создание панели и отзыв права доступа. Проверена сборка схем 18 slash-команд. Реальное подключение к Discord не проверялось: токен не предоставлен. После запуска проверь `/post`, `/post_edit`, `/collection_set`, `/collection`, `/snake` на своём сервере.

Документация используемого API: https://discordpy.readthedocs.io/en/stable/interactions/api.html
